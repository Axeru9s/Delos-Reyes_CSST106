# Printed lab report checklist

Capture the selected inputs, settings, method, and outputs from each lab page.
For larger figures, use the download control under the preview. Record sample
names or use your own input filenames in figure captions.

| Activity | Suggested evidence |
| --- | --- |
| 1 · Image Manipulation | Original image and shape, one RGB pixel reading or edit, grayscale, a region of interest, a resize, and a 90° rotation |
| 2 · Edge Detection | Original grayscale, Sobel X and Y, combined Sobel magnitude, and Canny result with the kernel size and thresholds |
| 3 · Histogram & Contrast | Original and enhanced images, intensity histogram overlay, and CLAHE clip and tile settings |
| 4 · SURF Feature Detection | Requested and active detector, keypoint counts and matching visualization. Record ORB fallback when it runs |
| 5 · PCA & Eigenfaces | LFW split summary, component count, eigenfaces, variance curve, test accuracy and classification report |
| 6 · YOLO Object Detection | Original and annotated image, model and confidence threshold, and detections table |
| 7 · Segmentation Techniques | Original image and classical comparison, with a separate semantic overlay, mask and predicted classes where the model is installed |
