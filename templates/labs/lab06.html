Train with a custom dataset

Put images and matching labels in train and validation folders under datasets/custom/. Name each label file after its image and store one line per object as class x_center y_center width height using zero-based class IDs and normalized coordinates.

# datasets/custom/data.yaml
train: images/train
val: images/val
names:
  0: example
yolo detect train model=yolo11n.pt data=datasets/custom/data.yaml epochs=30
yolo detect val model=runs/detect/train/weights/best.pt data=datasets/custom/data.yaml
yolo detect predict model=runs/detect/train/weights/best.pt source=datasets/custom/images/val
