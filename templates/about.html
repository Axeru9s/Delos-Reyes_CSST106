About & setup

Run the hub locally and prepare reproducible results for the printed lab report.

Local installation

Use Python 3.11 or 3.12 and run these commands from the project root.

python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m flask --app app run

On Windows PowerShell, activate with .venv\Scripts\Activate.ps1. Open localhost:5000.

LFW dataset

Lab Activity 5 downloads aligned Labeled Faces in the Wild images into datasets/ on the first run. Synthetic practice faces run offline. Use LFW results for the facial recognition report.

See the README for prefetching and cache locations.

Pretrained models

Install the optional dependencies for Lab Activity 6 and the semantic method in Lab Activity 7.

python -m pip install -r requirements-models.txt

Weights download into models/ on first use. If the download fails, use the README’s direct links and place the files there manually. Standard OpenCV wheels can run ORB and SIFT. SURF requires a nonfree-enabled contrib build.

Report evidence

Record the lab number, input, selected method, parameters, and any active fallback. Capture the result panel or download the output images using the icon below each figure.

Sample credits, model details, and a lab-by-lab report checklist are included in the source.
